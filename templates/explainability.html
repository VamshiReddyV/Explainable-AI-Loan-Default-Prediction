Methodological Notice: Comparing SHAP and LIME

SHAP and LIME employ fundamentally different mathematical methodologies. SHAP calculates Shapley values using cooperative game theory to measure global marginal attribution relative to the base value. LIME builds a local sparse linear surrogate model around the applicant's perturbed neighborhood. Because their mathematical frameworks differ, their numeric values are not directly equivalent. This comparison focuses on directional agreement (whether both algorithms identify a feature as escalating or mitigating default risk).
