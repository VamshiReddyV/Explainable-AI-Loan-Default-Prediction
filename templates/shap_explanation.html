Cooperative Game Theory

Developed by Nobel Laureate Lloyd Shapley (1953), Shapley values assess the marginal contribution of each feature across all possible feature subsets (coalitions). This guarantees efficiency, symmetry, and additivity.

Additive Feature Attribution

The sum of all feature attributions plus the base value equals the predicted probability for the applicant: f(x) = E[f(x)] + ∑ Φi.
